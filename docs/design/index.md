Monad's public design documentation explains the product intent and the visual system shared by user-facing surfaces. Repository-specific implementation and writing rules stay with the internal development documentation.

## Design foundations

| Document | What it explains |
|---|---|
| [Product principles](/design/product-principles) | The audiences, product boundaries, evidence standards, brand commitments, and accessibility baseline |
| [Design system](/design/design-system) | The color, surface, typography, spacing, motion, and responsive model used by the web UI |

## Implement a product surface

Start with the public foundations above. Contributors should then follow the [repository-only design rules](https://github.com/Monadix-AI/monad/tree/main/docs/internal/development/design) for shared components, interaction behavior, accessibility checks, and interface copy.
