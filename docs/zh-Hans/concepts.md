本指南定义用户、运维人员和开发者共用的运行时对象。实现与扩展术语请参阅[开发者参考](/internals/reference)。

## Agent 团队运行时

Monad 是采用无头架构、以守护进程为核心的 Agent 团队运行时。运行时独立于客户端维持团队，并负责身份、能力、权限、工作状态、产物、审批和审计历史。

无头意味着 Web UI、CLI、TUI、编辑器、API、消息渠道和自定义 Web 体验都是客户端。它们可以关闭、重连或替换，而不会取得团队或工作的所有权。

## 守护进程

守护进程是唯一长期运行的 Monad 进程。它存储持久状态、执行策略、公开协议、协调团队，并连接客户端与 Agent 运行时。默认只绑定本地接口；传输和远程访问行为见[运行时、配置与安全](/internals/infra/runtime)。

## Monad Mesh

Monad Mesh 是守护进程对外提供的 Agent 团队运行时，负责团队身份、会话绑定、角色、委派、共享工作、观察、审批与恢复。

mesh 是用户实际操作的单位。不同运行时的 Agent 加入同一个 mesh，各自保留执行行为，而 mesh 保留一份关于「谁参与、发生了什么」的持久记录。单 Agent 配置使用同一套运行时，可以直接成长为团队而无需迁移工作。

## Agent 与团队成员

Agent 是团队中的推理和执行参与者。项目成员是其持久团队身份，可以比某个服务商进程或执行会话存在得更久。团队运行时以该身份管理能力、策略、工作分配、会话绑定、观察和恢复，而不会从显示名称猜测身份。

## Agent 运行时

Agent 运行时执行一次 Agent 回合：接收输入、调用模型或服务商特定循环、执行获准操作并返回事件或结果。以下几类都可以作为 mesh 成员：

| 运行时 | 说明 | 接入方式 |
|---|---|---|
| **Monad Agent Runtime** | Monad 随附并默认使用的第一方 Agent 运行时 | 内置 |
| **第三方 Agent 服务商** | Codex、Claude Code、Gemini CLI、Qwen Code 等服务商原生运行时 | 第三方 Agent 适配器 |
| **ACP Agent** | 通过 Agent Client Protocol 接入的 Agent，包括编辑器侧 Agent | ACP 委派 |
| **对等守护进程** | 同一操作者拥有的另一个 Monad 守护进程 | 对等联合 |

Monad Agent Runtime 除了「随附」之外没有特殊地位，它只是成员之一。任何 Agent 运行时都不拥有团队身份、协作状态或客户端展示——这些归 mesh 所有。

## 会话

会话是一条持久工作线程，包含消息、事件、审批和执行状态，关闭客户端或重启守护进程后仍会保留。独立会话没有项目；项目会话把项目成员绑定到同一工作线程，同时保留稳定身份和运行时特有状态。

## 项目

项目是持久协作环境，包含标题、工作区根目录、成员名单、配置以及零个或多个会话；项目本身不是聊天记录。每个项目会话拥有自己的消息、成员绑定、投递、运行时会话、审批和可选计划。工作区与身份规则见[项目会话](/internals/agent-team-runtime/project-sessions)。

## 任务与计划

任务是分配给 Agent 或由团队协调的持久意图单元，应可检查、可中断、可恢复，并关联参与者、活动、审批和输出。当前实现使用会话、项目任务状态、委派记录和可选会话计划；Monad 尚未定义通用分布式任务模式。

## 协作状态

协作状态记录谁在参与、各成员在做什么、做出了哪些决定、还被什么阻塞，以及 Agent 之间的工作关系。守护进程拥有这份状态，各客户端按自身界面展示。

## 产物

产物是补丁、文件、报告、来源集合、计划或审查结果等持久输出。它与产生它的任务和活动保持关联，使人和 Agent 能检查来源，而不只依赖聊天文本。

## 审批与审计

审批是在受控操作执行前由人作出的决定边界；审计是理解事件经过所需的请求、决定、操作和结果的持久记录。二者让渐进式自治具备可问责性。

## 客户端

客户端呈现并控制守护进程拥有的状态，包括 Web UI、CLI、TUI、编辑器桥、API 和消息渠道。客户端可提供界面特有的交互，但不能成为跨客户端能力的唯一所有者。

## Workplace Experience

Workplace Experience 是守护进程所拥有的 Agent、任务、产物、审批和协作状态在 Web 端的投射。它能按编码、研究、运营、内容等领域组织浏览器交互，但不会创建另一份事实来源。Experience 的选择与渲染留在 Web 客户端，其他客户端继续使用相同运行时协议。

## 能力与扩展

能力定义 Agent 或客户端在运行时策略下可以做什么。Monad 可通过模型服务商、技能、MCP 服务器、Atom Pack、Hook、渠道、Agent 适配器和 Workplace Experience 扩展能力。扩展不能绕过守护进程权威；其输入仍不受信任，注册行为必须遵守清单、模式、审批和沙箱边界。

## 联合

对等联合在同一操作者拥有的 Monad 守护进程之间委派工作，使另一台机器上的守护进程可以作为 mesh 成员参与。具有独立信任和计费的跨所有者协作属于 Monadix。

## 当前边界

Monad 当前不宣称在本地运行时内提供任意分布式调度、通用任务与产物模式，或跨所有者身份与信任。产品边界见[Monad 是什么](/zh-Hans/product)，操作方法见中文使用指南，实现细节见[开发者架构](/zh-Hans/internals/index)。
